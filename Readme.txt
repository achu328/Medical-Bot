Medical Bot:

It is an interactive chat bot created by using SQL, MONGODB, Streamlit. The Bot is replying with the knowledge from GPT-4-O- Mini Model. 


Features:
1.It is multifultional chat bot that stores the clients information in SQL Database and stores the client's chat history in Mongo DB.
2. Both the information and the chat history were taken from the respective databases with the help of multiple functions.
3. With those information and client's current chat, the AI Model with converse with the client and empathise with him and help him to move further in his medical state.
Note - The CHATBOT will not diagnose or treat any illness. It will give some advices to the client.
